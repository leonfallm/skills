# leonfallm/skills

Agent skills live under `skills/<category>/<name>/` — each a folder with a `SKILL.md`
(plus optional `scripts/` and `references/`).

Install: `npx skills@latest add leonfallm/skills` (pick skills + agents), or as a Claude
Code plugin (`/plugin marketplace add leonfallm/skills`). Each skill is self-contained and
declares its own dependencies in its `SKILL.md`.
